## Security

### Reporting Security Issues

To report a security vulnerability of Pyodide runtime or any related components, please report it through
[GitHub Security Advisories](https://github.com/pyodide/pyodide/security/advisories?state=Triage).

Please DO NOT report security vulnerabilities through public GitHub issues or pull requests or any other public channels.

Please include the requested information listed below to help us better understand the nature and scope of the possible issue:

- Type of issue (e.g. buffer overflow, sandbox escape, remote code execution, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit the issue

This information will help us respond to the security issue more effectively.

Pyodide is an open-source project run by the volunteers and contributors, so we do not have a dedicated security response team or a bug bounty program.

### Supported Versions

Only the main branch of all the Pyodide runtime and other related components is actively maintained.
If you are using an older version, please upgrade to the latest release to receive fixes.

When reporting a security issue, ensure that it can be reproduced on the latest main branch.

### Preferred Languages

We prefer all communications to be in English.
